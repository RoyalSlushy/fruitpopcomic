## Why these matter

For a comic site the artwork *is* the design. The palette, type pairing, and page
rhythm should be derived from the real pages and the real wordmark, not chosen
first and retrofitted. Committing these unblocks the visual-world step.

Highest value first: **the logo**, then **one or two finished pages**, then
**character art**.
